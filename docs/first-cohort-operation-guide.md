# 第1期生募集ページの更新方法

## 現在の状態

トップに第1期生の案内を追加し、`/recruitment/first`に専用ページを用意しました。現在は**募集準備中**です。第0期生については「研修が始まっている」とだけ案内し、人数・実績・感想・写真を追加していません。

このページは受講相談用です。申込み・契約・決済を受け付ける機能はありません。連絡先は電話0985-74-7643で、LINEは追加していません。

## 募集情報を変更するファイル

GitHubで`lib/recruitment.ts`を開いて編集します。公開する内容は`confirmed`、まだ決まっていない案は`draft`に入れます。

| 項目 | 設定名 | 入れ方 |
| --- | --- | --- |
| 研修開始日 | startDate | 確定した日を`YYYY-MM-DD`形式で入力 |
| 第1期生の研修時間 | trainingTime | 確定した時間・補足説明を文字で入力 |
| 募集開始日 | recruitmentStartDate | 確定した日を`YYYY-MM-DD`形式で入力 |
| 募集締切日 | deadline | 確定した日を`YYYY-MM-DD`形式で入力 |
| 定員 | capacity | 確定した正の整数を入力 |
| 会場 | venue | 確定した会場名・住所・アクセスの案内を入力 |
| 募集状況 | status | 下記の状態から選択 |

未確定の値は`null`のままにします。架空のサンプル日付や会場を入れず、確認できた項目だけを`confirmed`へ移してください。`draft`はページへ表示されませんが、公開GitHubリポジトリ上のファイルです。個人情報・機密情報・管理用の認証情報は書かないでください。

料金やプログラム共通の期間・頻度は今回変更していません。変更が必要な場合は、トップ・募集ページ・法的案内の整合性をまとめて確認してから依頼してください。

## 募集状況の切り替え

- `preparing`：募集準備中。現在の設定です。
- `open`：募集受付中。募集開始が確定し、主催者が案内を承認してから設定します。
- `closed`：募集終了。主催者の確認後に設定します。

`publicationApproved`は現在`false`です。未確認のまま`true`へ変更しないでください。`open`の表示には、この承認と有効な募集開始日が必要です。未来の開始日、無効な日付、承認のない状態では「募集受付中」になりません。締切を過ぎている場合はビルド時の判定で終了表示になります。

**ページは静的生成です。時刻だけで公開中の画面が切り替わる仕組みではありません。** 募集開始日・締切日には、主催者が状態を確認し、設定を更新して再デプロイしてください。日付判定は日本時間です。締切日の具体的な受付時刻は未確定のため追加していません。

## 更新・確認の流れ

1. Codexへ「第1期生の募集情報を更新」と依頼し、確認済みの原稿を渡します。自分で編集する場合も、mainへ直接保存せず新しいブランチに保存します。
2. PRの変更内容とVercelのPreviewを確認します。
3. スマホで日程・会場・定員・料金・FAQ・電話リンクを確認します。
4. 本人が公開内容を承認してからマージ・公開を判断します。今回の作業ではマージ・本番公開を行っていません。
