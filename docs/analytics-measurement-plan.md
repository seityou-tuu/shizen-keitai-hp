# アクセス解析の導入設計（未接続）

更新：2026年11月5日（日本時間）。対象：PR #6。

**計測サービス・SDK・タグ・外部送信・Cookie・識別子の保存は追加していません。** この文書は将来の設計案です。現在のHPで、下記イベントを取得しているという意味ではありません。ブラウザQAで取得するローカルの表示指標は、計測サービスに送信せずテスト端末内だけで確認します。

## 目的とイベント案

| イベント    | 将来の取得タイミング案                              | 送信する値の上限                                                                  | 分からないこと                                     |
| ----------- | --------------------------------------------------- | --------------------------------------------------------------------------------- | -------------------------------------------------- |
| phone_click | 利用者が電話リンクを操作                            | `location`をhero / training / courses / contact / footer / sticky等の固定値に限定 | 実際の発信・接続・通話完了・受講申込みは分からない |
| line_click  | LINE開設・URL設定後、友だち追加リンクを操作         | 同じく固定の`location`のみ                                                        | 友だち追加・メッセージ送信・相談成立は分からない   |
| course_view | コース紹介の50％以上が1秒以上見えた場合を候補とする | `course_id`をjunior / instructor / headquartersの固定値に限定                     | 読了・理解・申込意思は分からない                   |

コース閲覧の閾値は運営判断前の案です。表示のたびに過剰送信せず、同一ページ表示中は同じコースにつき1回程度を候補にします。永続的な追跡IDは使わない設計を優先します。

## 送信しない情報

氏名、メール、個人の電話番号、LINEアカウントID/プロフィール、問い合わせ内容、健康情報、カード情報、認証情報を送信しません。リンク先URL、クエリ文字列、画面上の任意テキスト、完全な参照元URL、ユーザー固有ID、フィンガープリントもイベント値に含めません。事業者の電話番号やLINE URLも、イベント分析の値としては不要です。

ページを区別する場合は、承認済みの固定ページIDだけを使います。IPや端末情報をサービス側が自動取得する可能性もあるため、上記だけで個人情報を一切扱わないと断定しません。

## 導入前の判断・確認先

- 主催者：計測目的、必要なイベント、保管期間、閲覧担当、削除方法、利用者への案内を決定。
- サイト担当：サービスの自動取得項目、IP処理、国外移転・委託先、Cookie/識別子、同意設定、オプトアウト、Preview除外を確認。
- プライバシー担当・必要に応じ専門家：実際の運用に合わせて方針・同意の要否・記載内容を確認。現時点で法的適合を保証しない。
- 計測会社：必要最小限のデータ・保管設定が利用できるか、契約・利用条件を確認。

## 将来実装する場合の安全条件

1. 主催者が接続・送信内容を承認してから実装する。現時点では接続しない。
2. Preview/ローカルでは送信しない。必要な同意が得られるまで計測を開始しない。
3. 許可されたイベント名・固定値だけを送信し、任意テキストやリンク先URLを取り込まない。
4. 計測失敗でも電話・LINE・ナビゲーションを妨げない。重複リスナーや大きいライブラリを避ける。
5. ログに個人情報を残さず、テスト環境で許可外の値が送信されないことを確認する。
6. 実際のクリック数を「問い合わせ数」「申込数」「売上」と同一視しない。

## Vercel Toolbarとの区別

Vercel Toolbarはプレビュー上の確認用機能で、受講生募集の計測サービスではありません。このリポジトリにはToolbar用ライブラリを追加していません。プラットフォーム側の注入設定はコードだけでは確定できないため、管理者がVercelのプロジェクト設定と、本番URLをログアウト/シークレットウィンドウで開いた一般閲覧者の表示を確認してください。Productionで一般閲覧者に表示される設定なら、管理者が見直します。今回、VercelのProduction設定は変更していません。
