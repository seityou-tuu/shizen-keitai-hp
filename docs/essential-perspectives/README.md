# Four Essential Perspectives
A（4本柱）は比較しやすいが関係性が弱い。C（カード進化）は既存と調和するが差別化が小さい。B（中央図解）は4視点の並列性とつながりが伝わるため採用。
PCは円形の中央シンボルから4方向へ線を接続。スマホは小さなシンボルと縦方向の体系へ切替。番号は順序・優劣を意味せず、効果保証ではないと明記。
SVGは同じストローク幅で、やさしい接触・微細な動きの観察・胸郭と柔らかな呼吸波・理論と実技の循環を表現。装飾SVGはaria-hidden/focusable=false。新しいアニメーションや依存は追加せず既存PR #21の見出し演出を維持。
