## 改善前後

| 箇所 | 改善前 | 改善後 |
| --- | --- | --- |
| 研修 | 見出しと実技説明が同じカラムに並び、実技と理論の関係を読み取る必要がある | セクション冒頭に対面／オンライン・頻度・時間を対比。大小の実技写真と、控えめな色面の学び合い写真でリズムをつける |
| 資格コース | 横長の説明行が3つ続く | PCは段差を持つ3段階の構成、スマホは縦につながる経路。料金欄へのリンクを追加 |
| 講師紹介 | 写真を縦長に切り抜き、大きな見出しの下に配置 | 写真全体を表示。写真・名前・既存の経歴と資格を一体の紙面として配置 |
| 料金 | 同じ研修日程を各コースで3回説明 | 3つのコース名・期間・料金を揃え、共通日程を一か所に集約 |
| 動き | 全セクション共通のスクロール演出 | 研修写真・主要見出しに限定した一度だけのフェードと移動。ほかの欄は静かな読み物として維持 |
| 相談 | 研修直後とロードマップ直後に同様の電話CTA | 研修直後の重複を削除。ロードマップ・料金・最終窓口・既存固定ボタンで相談できる |

ヒーローの写真・深緑グラデーション・白とゴールド・12セクション・既存写真8枚・料金・電話・会社情報・プロフィールの事実・SEO設定を維持。新規写真、口コミ、認定条件、LINE導線、ライブラリは追加していません。

## 再検証

`npm run build` → `npm run start -- --port 3100` の後、既存PlaywrightとChromiumを指定して実行します。ブラウザ用ライブラリをプロジェクトへ追加する必要はありません。

```sh
PLAYWRIGHT_MODULE_PATH=/path/to/playwright CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm run test:browser
```

新レイアウトに合わせ、ブラウザ検証の写真順序と共通料金日程の検証先を更新しました。既存メニューの矢印がアクセシブル名に含まれるため、完全一致名で失敗していた取得方法も修正しています。
