# 3セクションのデザイン改善

2026年11月6日（日本時間）。PR #14反映済みmain `1b71d29`から作成した`feat/pr15-section-design`のレビュー資料です。PR #15として依頼された作業ですが、実際のPR採番・作成完了は別途確認が必要です。

## それぞれの改善

| セクション | 変更内容・理由 |
| --- | --- |
| その一手には、理由がある。 | 4列の文字中心の構成を、番号・見出し・本文・図解の2×2の構成へ変更。触れる手、反応を確かめる円、呼吸の波形、繰り返し学ぶ循環という異なる概念図で、4つの視点を識別しやすくしました。スマホでは1列にし、番号と図解から見出し・本文へ読み進められます |
| 積み重ねた経験に、新しい視点を。 | 同じ横長の行が続く構成を、経験者側を主とした深緑の紙面と、少し段差をつけた白い紙面へ変更。対象を示すラベル・見出し・説明の優先順位を整理し、経験の積層と関心の起点を線で表しました。スマホでは上下の順序を維持して自然に読み進められます |
| 技術を身につけた、その先へ。 | 5項目の均一なリストを、最初の「施術の選択肢」を大きく見せる非対称の構成へ変更。選択肢の広がりを示す分岐図と、残り4つの読みやすい紙面を組み合わせました。タブレットでは最初の項目を横長、スマホでは縦の構成へ切替。達成順序や認定・収益の保証を示すタイムラインにはしていません |

3セクションが同じ構成にならないよう、視点は「図解で比較」、対象者は「濃淡と段差で読み分け」、学んだ先は「非対称のまとまり」で表現しています。写真の追加や置換は行っていません。深緑・白・ゴールド、既存の見出しと本文、項目順、注意書きを維持しています。

図解は解剖図・効果の実証画像ではなく、文章を補助する概念表現です。読み上げでは既存の本文を読むよう、図解を`aria-hidden`にしています。ホバー時は枠線・背景の控えめな変化だけで、本文は常時表示。動きを減らす設定では新しいトランジションを付けません。
