- 問い合わせ欄はLINEを先、電話を補助に配置。LINE相談が正式な受講申込み・契約・決済ではないことを明示。
- 深緑・白・ゴールド、PR #15までの本文・写真・料金・セクション構成を維持。

LINEウィジェット・SDK・フォーム・QR・計測送信は追加していません。リンクは利用者の操作で別タブに開き、`noopener noreferrer`を指定しています。受付時間・返信時間等は推測していません。

## 公開前の確認

実際のLINEアプリ・ブラウザーで正しい公式アカウントが開くこと、相談の受付担当・案内文・個人情報の取扱いを運営者が確認してください。実機での電話発信・応対は未検証です。URLの主催者確認は受領済みですが、ローカルの置換テストで実際のアカウント状態・返信を検証したとは扱いません。

LINEを正式な申込み方法としては設定していません。第1期生LPへの反映は既存PR #9で別に行い、募集LPのProduction 404・noindex等を維持します。mainへのマージ・本番公開は行っていません。

GitHub APIの制限が残る場合は、[公開HP用PR作成画面](https://github.com/seityou-tuu/shizen-keitai-hp/pull/new/feat/official-line-contact)から、準備した[PR本文](PR.md)を使用できます。VercelのPreview URL・デプロイ成功は取得できた場合のみ報告します。
