# PR #29 スマホ最終品質改善

基準はPR #29初版 `4d267da`。同じ `feat/premium-learning-experience` ブランチへの追加変更です。新規PR、マージ、本番公開、検索設定の変更は行いません。

## 今回の変更

- **動画**：700px以下は1列にし、サムネイルを本文幅いっぱいに表示。containで画像全体を見せ、2本とも同じ比率・間隔・操作リンク・再生数・出典の配置に統一。701px以上の2列は維持。YouTube URLと元画像は維持し、iframe・自動再生は追加していません。
- **3コース**：700px以下だけ、既存の縦ラインと左のSTEP番号を軸に、コース名→英語表記→説明→期間→料金リンクを配置。余白を整理し、400pxのセクション高は2343→2033px。768/1024/1440pxの同セクション高は変更前と一致します。
- **既存実績**：「施術歴15年」「YouTube総再生回数220万回」を同じ数字用タイポグラフィで強調。「Fann Channel 2024 グランプリ」の見出しも読みやすく拡大。文言を分割して装飾しており、出典・過去値の注記・写真・実績そのものは変更していません。実績の重複掲載も追加していません。
- **固定CTA**：ソースに既存のsafe-area余白があり、検証で問題は確認されなかったため、実装は変更していません。

最終確認で、モバイルのgrid化により既存の行指定が再適用される点を調整し、タイトル・説明・期間・料金リンクの視覚順序を回帰テストに追加しました。番号を2段で表示するため、既存テストはSTEPラベル全体ではなく番号そのものの不要な折り返しを確認します。実績テストも、装飾タグではなく表示文字列を検証し、注記・実績の保持を引き続き確認します。

## 内容・保護対象

320/375/390/400/430/768/1024/1440pxで通常HP全文を空白以外一致確認。リンク先とラベル、画像ソースとaltも一致。ファーストビューはCanvasを比較撮影時だけ非表示にして全画素を比較しました。背景自体は別の通常モーション検証で確認しています。

## 固定CTA・セーフエリア

320/375/390/400/430pxで、通常の下部余白0pxと合成34pxの2条件を検証しました。実際のCSS宣言内にある `env(safe-area-inset-bottom, 0px)` を、テスト用のブラウザ文書内だけで34pxへ置換して、同じカスケード・calc計算を使用しています。アプリのCSSファイルは変更していません。

CTAのリンクは縦横44px以上、下部paddingは10→44px。コース料金リンク・動画リンク・相談欄・フッターのリンクを画面内へスクロールし、CTAに隠れずヒットテスト可能なこと、ページ最下部がCTAより上に表示できることを確認。スマホでサイドナビが非表示になることも確認しました。

この環境のChromiumにはCDPのsafe-area注入APIがなく、上記はCSSの合成検証です。iPhone Safariの実機・ホームインジケータ・動的ツールバーを確認したという意味ではありません。実機確認は残しています。

## TBTの調査と再測定

過去の「241→310ms」のLighthouse記録を調査しました。スクリプト取得本数は前後とも10本で、総リソースサイズ差は小さく、新しい大きなJavaScriptが追加された状況ではありませんでした。Style & Layoutの中央値は1036→1052ms、Script Evaluationは895→932msで、各回の分布も重なっています。これらはTBTと同じ指標ではなく、差分を足してTBTの原因とすることはできません。

特定の追加処理が+69msを発生させたという因果関係は特定できていません。既存の初期スクリプト評価・描画負荷と測定の変動を含む結果として記録し、速度改善を断言しません。保護対象のスプラッシュや背景を変更して数値だけを下げる対応はしていません。
