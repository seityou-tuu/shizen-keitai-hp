- 講師紹介の学び方を「技術を見る → 自分の手で確かめる → 振り返って次へ」の3段階に整理。既存の対面実技・オンライン理論・復習動画・質問対応の範囲で表現し、架空の本人発言・個別指導・追加サポートは設けていません。

- 最終相談の見出しを「『学んでみたい』を、相談するところから。」に更新。学び方・会場・料金の気になった点からLINEで質問できる案内にしました。相談料の無料保証はしていません。正式な受講申込み・契約・決済とは区別し、電話も維持しています。
- 日程データ、3会場切り替え、料金、3コース、締切、受講対象、講師の確認済みプロフィール・過去の220万回表記、既存写真4枚と公開制御は変更していません。今回の製品コードの対象は募集LPと専用講師コンポーネント・CSSのみです。
