# 第1期生LP：講師紹介と学びへの期待感の改善

対象は既存PR #9、`feat/first-cohort-recruitment-20261106`。今回の作業開始時点のmain `5ca6850`（PR #16）は既に取り込み済みです。mainへのマージ、本番公開、新規PR作成はしていません。

## 改善内容

- 講師紹介を、既存の肖像写真・施術歴・資格/経歴・プログラムの学び方で構成。既存の研修写真3枚は保持し、既存HPの肖像写真1枚だけを追加しました。写真の縦横比を保ち、装飾や新しいJavaScriptは追加していません。
- ファーストビューと概要で、0期生から第1期生へ続く学びを紹介。00→01の流れ、2027年1月開講、3会場、各会場6名を視覚的に整理しました。特典・優遇制度・保証は追加していません。
- 古い電話のみの説明を修正。LINEを主要な受講相談窓口とし、電話も維持。FAQ・相談フロー・末尾・メタ説明の整合性を確認し、正式申込み・契約・決済とは区別しました。
- 3会場切り替え・18日程・締切・料金・受講対象・研修内容・公開制御は維持しています。

## 使用情報と掲載を保留した情報

2026年11月6日の依頼で再確認された永友裕也先生の氏名、柔道整復師（2012年取得）、施術歴15年、2017年ながとも整骨院開院、自然形体療法理事を使用しました。YouTube総再生回数220万回は過去の確認情報で、最新値ではない旨を併記しています。共通データ`lib/instructor.ts`を使用するため、このブランチのトップページにも同じプロフィールが表示されます。公開中mainは変更していません。
