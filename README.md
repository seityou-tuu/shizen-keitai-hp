# 自然形体療法 資格取得プログラム

株式会社TSUNAGiの受講生募集サイトのデザイン試作です。Next.js App Router / TypeScript / Tailwind CSS 4で制作した、日本語・レスポンシブ対応の1ページサイトです。

## 開発

Node.js 20.9以上（推奨: Node.js 24 LTS）とnpmを使用します。

```bash
npm ci
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

```bash
npm run build
npm start
npm run typecheck
```

外部データベース・APIキー・必須環境変数は不要です。画像とフォントの外部取得も行いません。フォントは端末の日本語明朝・ゴシックにフォールバックするため、OSにより表示差があります。

## 研修紹介の改善（main基準・独立PR）

`components/learning-experience.tsx`に、悩み別の入口・確定数字の概要・実技と理論の研修紹介を集約しています。追加スタイルは`app/learning-experience.css`に分離しました。写真枠は引き続き`PhotoPlaceholder`を利用しており、実技・理論・既存講師紹介それぞれに、許諾済みの写真を後から差し替えられます。人物・研修写真や実績を創作していません。

参考URL（https://tadasu-seitai.jp/recruit/）は作業環境の通信制限（403）により閲覧できませんでした。依頼に記載されたメッセージ性・悩みからの導線・研修の具体化・数字の整理を独自に構成し、参考サイトの素材は使用していません。学習成果・認定条件は追加していません。

法定表示等の追加PRが未マージのため、`origin/main`から分岐して作成しています。料金表・フッター・既存ヘッダーは変更していません。法定表示PRがマージされたら、そちらのフッター4リンクを保持し、この研修改善部分と組み合わせてビルド・全リンクを再確認してください。両PRのREADME追記は双方を保持してください。会社概要・各種規約の準備状態は別PRの確認事項に従い、審査提出や公開準備の完了を意味しません。

この改善では本番ビルド・型チェック・差分検査が成功しています。Chromiumの320 / 390 / 768 / 1024 / 1440pxで横はみ出しがないこと、悩み別3リンク、モバイルメニュー、FAQ開閉を確認しました。正式ドメイン未確定によるmetadataBase警告は既存の公開前確認事項として継続しています。

## 構成

- `app/page.tsx`: 各セクションと料金・FAQデータ
- `app/globals.css`: 配色、レイアウト、レスポンシブ、動きを減らす設定
- `app/layout.tsx`: 日本語設定、SEOメタデータ
- `app/opengraph-image.png` / `app/twitter-image.png`: 人物写真を使わない英字OGP画像
- `components/header.tsx`: 固定ヘッダーと開閉式モバイルナビ
- `components/ui.tsx`: 共通見出し、写真仮枠、リンク

FAQはネイティブのdetails要素を使用。キーボードフォーカスと本文スキップリンクに対応。月別研修表は小画面で横スクロールできます。問い合わせへのリンクはページ内の「窓口準備中」案内に移動し、送信フォーム・架空の連絡先はありません。
