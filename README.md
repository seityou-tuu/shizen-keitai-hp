# 自然形体療法 資格取得プログラムHP

深緑・白・ゴールドのNext.jsサイトです。正式公開URLは https://shizen-keitai-hp.vercel.app/ です。

今回の変更は **PR #6 / `feat/program-site-renewal`** に追加しています。mainへのマージ・本番への直接反映は行いません。プレビューを確認してから、管理者が公開を判断してください。

## 現在の機能

- 既存写真8枚による施術・研修・永友先生の紹介。画像比率を維持し、トップ以外は遅延読み込み。
- 各コース6ヶ月・990,000円（税込）、3コース合計2,970,000円（税込）。実技月1回・対面9:00〜17:00、理論月1回・オンライン1回2時間。
- 電話相談：0985-74-7643（スマートフォンでタップ発信）。受付時間は未確認です。
- 受講相談・資料請求・一般問い合わせ用フォーム。正式申込み・契約・決済は受け付けません。
- **Formspree未設定ではフォーム送信できません。** 電話への案内を表示します。
- フォームはサーバー側でも検証し、Formspreeの正常な受付応答を確認した場合だけ完了表示。通信失敗時は入力を保持し、自動再送しません。
- FAQは標準の`details/summary`で開閉し、追加のJavaScriptを使いません。
- canonical・OGP・favicon・robots・sitemapを整備。プレビューは常にnoindexです。本番も既存の検索登録停止を初期値として維持しています。

## Formspreeを接続する手順

1. 主催者が受信先メールアドレスを決め、[Formspree](https://formspree.io/)に登録します。この作業ではアカウント・受信先を作成していません。
2. Formspreeで新しいフォームを作り、受信先メールの確認手続きを完了します。
3. 表示された `https://formspree.io/f/…` の末尾のフォームIDをコピーします。URL全体・メールアドレス・APIキーを設定するものではありません。
4. Vercelの対象プロジェクト → **Settings → Environment Variables** で `FORMSPREE_FORM_ID` を作り、実際のIDを値に設定します。最初は **Preview** を選びます。受信先はFormspree側で管理します。
5. **Deployments → 対象ブランチの最新デプロイ → Redeploy** で再ビルドします。設定後の再デプロイが必要です。
6. プレビューの「お問い合わせ」で準備中表示が消えたことを確認します。テストと明記した内容を1件送信し、画面の受付完了だけでなく **Formspreeの受信一覧と受信先メールの両方** を確認します。
7. 通信失敗・入力エラー・迷惑送信対策・受信後の対応を確認します。送信状態が不明なときは、自動再送しません。
8. 管理資料の確認事項を解消し、本番利用を判断した後で **Production** にも同じ変数を設定します。実際の公開は管理者のmainマージ後に行います。

Formspreeの受信許可ドメイン設定がある場合は、正式URLと確認するプレビューURLを許可してください。プランに応じて迷惑送信フィルター、CAPTCHA、通知、利用上限を確認してください。CAPTCHA等の設定がAPI送信を拒否する場合は、準備中へ戻して設定を確認します。送信が成功していない状態を完了として扱いません。

この実装の`FORMSPREE_FORM_ID`はサーバー側だけで使います。フォームID自体はFormspreeの公開接続識別子であり、秘密のAPIキーではありません。秘密情報や受信先メールをソースへ埋め込まないでください。`.env.local`等はGit管理外です。雛形は[.env.example](.env.example)にあります。

フォームの入力はこのアプリの処理では保存・ログ出力しませんが、送信後はFormspree・メールサービスで扱われます。主催者はプライバシーポリシー、保管期間、外部委託・国外取扱い、削除手順、受信担当者を確認する必要があります。既存ポリシー本文は今回変更していません。

## 開発と確認

Vercelと同じNode.js 24.xを推奨します。

```sh
npm ci
npm test
npm run build
npm run typecheck
npm run dev
```

ローカルでは `.env.example` を `.env.local` にコピーし、必要な値だけ設定します。フォームIDがなければ空欄のままで構いません。

- `npm test`：入力検証、未設定、同一送信元制限、送信量上限、Formspreeの成功/失敗・通信障害、検索登録制御を確認。外部送信はモックで、実メールは送りません。
- Lintの設定・スクリプトはありません。今回、依存ライブラリは追加していません。
- この作業環境には対応するブラウザ操作機能がないため、実画面でのPC/iPhone Safari確認と実際の送受信は未実施です。確認手順は運用マニュアルを参照してください。
