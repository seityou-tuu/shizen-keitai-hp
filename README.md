# 自然形体療法 資格取得プログラム

株式会社TSUNAGiの受講生募集サイトのデザイン試作です。Next.js App Router / TypeScript / Tailwind CSS 4で制作した、日本語・レスポンシブ対応の1ページサイトです。

## 開発

Node.js 20.9以上（推奨: Node.js 24 LTS）とnpmを使用します。

```bash
npm ci
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

```bash
npm run build
npm start
npm run typecheck
```

外部データベース・APIキー・必須環境変数は不要です。画像とフォントの外部取得も行いません。フォントは端末の日本語明朝・ゴシックにフォールバックするため、OSにより表示差があります。

## 構成

- `app/page.tsx`: 各セクションと料金・FAQデータ
- `app/globals.css`: 配色、レイアウト、レスポンシブ、動きを減らす設定
- `app/layout.tsx`: 日本語設定、SEOメタデータ
- `app/opengraph-image.png` / `app/twitter-image.png`: 人物写真を使わない英字OGP画像
- `components/header.tsx`: 固定ヘッダーと開閉式モバイルナビ
- `components/ui.tsx`: 共通見出し、写真仮枠、リンク

FAQはネイティブのdetails要素を使用。キーボードフォーカスと本文スキップリンクに対応。月別研修表は小画面で横スクロールできます。問い合わせへのリンクはページ内の「窓口準備中」案内に移動し、送信フォーム・架空の連絡先はありません。

## 検証メモ

本環境のプロセス制約を考慮し、開発・ビルドにはNext.js標準のWebpackモードを使用します。OGP画像はビルド時の外部フォント取得を避ける静的PNGです。正式ドメイン確定までは相対画像URLとなるため、公開時にmetadataBaseを設定してください。

検証済み: 本番ビルド、TypeScript型チェック、Chromiumの320 / 390 / 768 / 1440px幅（ページ全体の横はみ出しなし）、モバイルメニュー開閉とリンク遷移、FAQ開閉、問い合わせ案内への移動、OGP画像HTTP 200。実際の問い合わせ送信は未実装のため対象外です。
